# Spendly

Spendly is a mobile-friendly, installable daily expense tracker. It stores entries in the browser on each person's device, so they are private and available offline after the first visit.

## Share it as a link

Publish the entire `expense-tracker` folder with any static website host that provides HTTPS. For example, create a new Netlify site and drag this folder onto its deploy page, then send the generated URL to anyone you want to use the app.

This repository includes a GitHub Pages deployment workflow. In **Settings → Pages**, choose **GitHub Actions** as the source once; the deployed URL can then be shared like any other website.

## Install on a phone

1. Open the published HTTPS link in Safari (iPhone) or Chrome (Android).
2. Choose **Add to Home Screen** / **Install app** from the browser menu.
3. Open Spendly from the new home-screen icon.

## Privacy and sharing

Sharing the link shares the app, not anybody's expenses. Every device has its own private local expense list. To let multiple people track the same ledger and see one another's changes, the app needs user accounts and a shared database.
